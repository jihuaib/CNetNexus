# 隧道 CLI 文档

Tunnel 模块（module-id: 12）展示 MPLS 隧道相关状态，当前 CLI 面以 `show` 命令为主。

## 查看命令

| 命令 | 视图 | 说明 |
| --- | --- | --- |
| `show tunnel` | global | 显示隧道总览 |
| `show tunnel candidate` | global | 显示候选隧道 |
| `show tunnel nhlfe` | global | 显示 NHLFE |
| `show tunnel ftn` | global | 显示 FTN |
| `show tunnel ilm` | global | 显示 ILM |
| `show tunnel watch` | global | 显示 watch 状态 |
| `show tunnel label` | global | 显示 label 状态 |
